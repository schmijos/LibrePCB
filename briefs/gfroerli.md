# Design brief: Water Temperature Node v1.0

You are the hardware engineer for a small open-source project. We need the PCB
for a battery-powered sensor node that is tied to a buoy on a lake. It
measures the water temperature with a probe hanging in the water, plus the air
temperature and humidity inside its enclosure, and sends the readings over
LoRaWAN (868 MHz, Europe) every few minutes. It must run for months on one
Li-ion cell.

The key components and everything that mates with the outside world (connector
pinouts, outline, battery, antenna connector) are fixed below. Everything else
— the supporting circuitry, component values, MCU pin assignment, placement
and routing — is your design decision. Write down why you chose what you chose.

Coordinates in this brief are in mm, board coordinate system, origin at the
bottom-left corner of the board's bounding box, X to the right, Y up.

## 1. Requirements

### A. Power

- **A1** Power comes from one 18650 Li-ion cell (2.8 V to 4.2 V) held by two
  Keystone 54 battery clips (one per cell end).
- **A2** The cell is replaced by end users and will sometimes be inserted
  backwards. The board must survive reverse insertion. In normal operation the
  protection must not waste noticeable voltage (no series diode).
- **A3** All electronics run from 3.3 V generated by a TI LP5907-Q1 LDO
  (LP5907QMFX-3.3Q1, SOT-23-5). There is no power switch: the node runs
  whenever a cell is inserted.

### B. Battery voltage measurement

- **B1** The MCU measures the cell voltage with its ADC (input range 0 V to
  3.3 V).
- **B2** While not measuring, the measurement circuit must draw essentially no
  current from the cell (target < 1 µA). The MCU enables it only for a
  measurement.
- **B3** The divider ratio must be accurate to 0.2 % or better.

### C. Microcontroller

- **C1** NXP LPC11U24FBD48/401 (Cortex-M0, LQFP-48). See
  `datasheets/LPC11U24FBD48-pinout.md`.
- **C2** Clock: 12 MHz crystal Abracon ABM8G-12.000MHZ-4Y-T3 (3.2 × 2.5 mm,
  4 pads: pads 1 and 3 are the crystal, pads 2 and 4 are the lid/ground), with
  load capacitors.
- **C3** Decouple every supply pin.
- **C4** Programming and debugging over SWD through a standard ARM 10-pin
  1.27 mm Cortex Debug header (CNC Tech 3220-10-0300-00 or equivalent),
  including reset (pinout in section 2).
- **C5** USB is not used.

### D. LoRaWAN modem

- **D1** Microchip RN2483 module (RN2483A-I/RM103), 868 MHz output (RFH).
- **D2** The MCU talks to the module over UART (57600 baud, no flow control).
- **D3** The module's 868 MHz RF output goes to an edge-mount SMA jack for
  1.6 mm boards (Cinch/Johnson 142-0701-801), onto which a stub antenna is
  screwed. Keep the RF path short and matched to 50 Ω.
- **D4** A service header (section 2) lets an external programmer update the
  module's firmware (PIC ICSP: PGC/PGD) and lets a PC talk to the module
  directly.

### E. Sensors

- **E1** Air temperature and humidity: Sensirion SHT21 (I²C, DFN-6 3 × 3 mm),
  placed on the tab (section 3). Its reading must not be biased by heat from
  the rest of the board: decouple it thermally as well as you can.
- **E2** Water temperature: Maxim DS18B20 (1-Wire) in a waterproof stainless
  steel probe with a 1 m 3-wire cable. The cable is soldered to a 3-pin header
  on the board (section 2). The probe itself is not assembled on the board.
- **E3** Further I²C sensors can be connected via an expansion header
  (section 2). The I²C bus pull-ups are on this board.

### F. User interface and development

- **F1** Three status LEDs, each on its own MCU GPIO, a few mA each: red
  (OSRAM LS R976-NR-1), yellow (OSRAM LY R976-PS-36), green (OSRAM
  LG R971-KN-1), all 0805.
- **F2** Header "UART0" to monitor or drive the MCU ↔ modem UART link.
- **F3** Header "UART1" to connect a USB-serial adapter for a debug console
  during development.

## 2. Connector pinouts (fixed)

All headers are 2.54 mm single-row through-hole pin headers unless stated
otherwise. "RX"/"TX" on UART0/UART1 are from the MCU's point of view.

| Header | Pin 1 | Pin 2 | Pin 3 | Pin 4 | Pin 5 | Pin 6 | Pin 7 |
|--------|-------|-------|-------|-------|-------|-------|-------|
| Water probe (1×3) | GND | DQ (data) | 3.3 V | | | | |
| I²C expansion (1×4) | 3.3 V | SDA | SCL | GND | | | |
| UART0 (1×2) | RX (MCU receives, = module TX) | TX (MCU transmits, = module RX) | | | | | |
| UART1 (1×2) | RX (MCU receives) | TX (MCU transmits) | | | | | |
| Modem service (1×7) | module RESET | module UART_RX | module UART_TX | module PGC | module PGD | 3.3 V | GND |

SWD (2×5, 1.27 mm, SMD), standard ARM Cortex Debug pinout:
1 VTref (3.3 V), 2 SWDIO, 3 GND, 4 SWCLK, 5 GND, 6 SWO (may be unconnected),
7 KEY (unconnected), 8 NC/TDI (unconnected), 9 GNDDetect (GND), 10 nRESET.

## 3. Mechanics (fixed)

The board fits a small enclosure. Its outline is this polygon (mm, in order):

```
(13, 90) → (51, 90) → (51, 26) → (41.53, 26) → (39, 23.45) → (39, 8)
→ (56, 8) → (56, 0) → (13, 0) → (13, 14) → (0, 14) → (0, 76) → (13, 76)
→ back to (13, 90)
```

Rough sketch (not to scale):

```
 Y

           |                     H1    |
 76  +-----+                           |
     |                                 |
     |  left        main body          |
     |  wing                           |
     |                                 |
 26  |                       +--.------+   <- notch for the antenna
     |                       |  (open, no board)
 14  +-----+                 | <SMA
           |       H2        +------------+
  0        +-------------------- tab -----+
     0     13               39            56  X
```

- **M1** Two M3 mounting holes (non-plated, Ø 3.2 mm to 3.5 mm) at
  H1 (34.5, 82.5) and H2 (34.5, 7.5).
- **M2** The 18650 cell lies on the top side with its axis parallel to Y,
  cell centre at (22.05, 38.2), positive terminal towards the top (higher Y).
  The cell including clips covers roughly X 13 to 31, Y 3 to 73: no other
  components there.
- **M3** The SMA jack sits on the notch edge X = 39 with its centre at
  Y ≈ 17 and points in +X into the notch (the antenna goes there).
- **M4** The SHT21 sits on the tab (X 39 to 56, Y 0 to 8), as far from the
  rest of the electronics as possible.
- **M5** The water probe header sits in the lower half of the left wing
  (X 0 to 13, Y 14 to 45); the probe cable leaves the enclosure to the left.
- **M6** All components on the top side.

## 4. PCB technology

- 2 layers, FR4 1.6 mm, 35 µm copper, standard low-cost prototype process.
- Minimum trace width and clearance 0.2 mm, minimum via 0.6 mm pad / 0.3 mm
  drill.
- Size power traces for the module's transmit peaks (about 40 mA).
- Ground planes as you see fit.
- Silkscreen: product name and version ("Water Temperature Node v1.0") and
  labels for the header pins, if your tools allow.
